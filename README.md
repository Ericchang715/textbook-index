# 教材選書室

此版參考使用者上傳的 index(1).html，沿用其中的 193 筆書目與 9 類學科。已配對全部 193 張產品資訊圖並建立縮圖，其中 192 張來自 bookinfo(1).zip，另 1 張為補充上傳的《跨文化管理》4 版資訊圖。

原始 ZIP 共有 193 個檔案，其中 192 個是 PNG，另 1 個是 desktop.ini。網站不包含設定檔。補入《跨文化管理》4 版後，193 筆書目均已連結圖片，目前沒有缺圖。

## 書目資料來源

193 筆書目來自參考 HTML 的 INITIAL_CATALOG_193 陣列。檔名共 193 個，未刪除參考資料標記的副本或勘誤項目。

程式實際記錄為中文 104 筆，中譯／雙語標註 20 筆，英文 69 筆。參考頁首寫成中文 103 筆與中譯 21 筆，本版改為依書目資料自動計算。

18 筆「副本與勘誤」標記沿用參考檔，不等於已比對圖片內容，也不代表其他 175 筆是經查核的不重複書籍。學科與語言同樣沿用參考資料，仍須依原圖確認。

配對時修正 1 個檔名差異：參考頁的「林蕙真_管理會計學-理論與應用(全一冊) 8e.png」，原圖實際使用「林蕙真_管理會計學-理論與應用(全一冊)_8e.png」。書目保留原檔名別名，支援兩種寫法配對。

image-match-report.json 記錄配對數量與缺圖項目。網站圖片改用原尺寸的無損 WebP，已逐張核對尺寸與 RGBA 像素完全相同；縮圖另外建立。原始 PNG 仍保留在使用者上傳的 bookinfo(1).zip 與本次補充圖片。

## 開啟與搜尋

解壓縮後開啟 index.html，無須安裝套件。網頁已內嵌全部程式與樣式，不依賴外部 CDN。

可搜尋作者、書名、原文參考資訊、版次、原始檔名與標籤。多個關鍵字採同時符合的方式，例如 Ross Finance。

側欄支援學科、教材類型、版次、作者首字與副本標記篩選。可切換圖卡、清單表或學科目錄，依書名、作者、學科、版次、檔名或匯入順序排序。

## 連結原圖

點選「連結產品資訊圖」或「整理圖庫」，選擇圖片資料夾，或直接匯入 ZIP。支援 JPG、PNG、WebP、GIF、AVIF。

系統依原始檔名配對既有書目，保留已整理的作者、書名、版次與分類。請保留圖片原有檔名，包含空格與括號。新檔名會新增為待確認書目；選擇部分圖片不會刪除其他索引。

圖片名稱對應既有書目時，即使不同檔案內容相同，也會保留各筆書目。尚未連結的項目可先查看書目詳情，畫面不會生成冒充原圖的資訊圖。

## 校對與備份

每筆可編輯作者、書名、原文參考資訊、版次、教材類型、學科、標籤與副本標記。確認後可勾選「已核對書名與其他書目資料」。

書目修改保存於目前瀏覽器，收藏也保存於本機。已選圖片保留在本次分頁，關閉前請匯出完整網站。

「匯出完整書目 CSV」包含所有書目欄位，可用 Excel 開啟。「備份分類 JSON」可用「匯入分類 JSON」還原書目與分類，JSON 不包含圖片內容。

## 上傳 GitHub Pages

1. 完成原圖連結與書目校對後，點選「匯出 GitHub 網站 ZIP」，再點選「下載網站 ZIP」。
2. 解壓縮下載的 ZIP，將解壓後的內容放在 GitHub 儲存庫根目錄。
3. 保留 index.html、catalog.json、images、thumbs、README.md 與 .nojekyll。未連結原圖時，ZIP 不含圖片資料夾。
4. 在 Settings → Pages 選擇 Deploy from a branch，指定 main 與 /(root)，儲存後等候部署。

可使用 GitHub Desktop 上傳整個資料夾。本次未指定儲存庫，尚未執行 GitHub 上傳或發布。

官方說明：
https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 更新

已匯出的完整網站 ZIP 可再次匯入，保留書目並載入其中原圖。由已部署網站開啟「整理圖庫」也可更新後再次匯出。

如果直接開啟本機已含圖片的 HTML，瀏覽器會限制再次打包時讀取本機圖片。請使用已部署的 HTTPS 網址，或將完整網站 ZIP 匯入後再更新。

匯出時保留網站圖片的檔案內容，檔案路徑改用流水號，原始中文檔名仍保存在書目。下載網站圖片時使用實際圖片格式的副檔名。網頁使用相對路徑，適用 GitHub 專案子路徑。
